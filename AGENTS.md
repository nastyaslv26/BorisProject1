# Правила работы

- Перед работой сначала прочитать `README.md`, `spec.md` и `PLAN.md`.
- Это самостоятельное Node.js-приложение; не переиспользовать как основу прошлый учебный кейс.
- Менять только согласованный скоуп: одна общая страница, пять слотов текущей даты, запись по ФИО, серверная защита от дубля и карточка последнего кормления. Не добавлять функции вне описанного сценария.
- SQLite — единственное хранилище состояния. Не вводить реальные ФИО, рабочие данные, секреты или внешние интеграции.
- Не проектировать базу данных как отдельную учебную задачу, не добавлять исключённые функции и не полировать сверх семи критериев DoD курса.
- Учитывать требуемые материалы результата: рабочий код, GitHub-репозиторий или архив, семь скриншотов, карточку кейса, демо и след одной итерации с ИИ. Сверяться с материалами курса для точного состава DoD.
- После каждой задачи предлагать наблюдаемую проверку результата.
