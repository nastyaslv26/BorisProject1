# План ручной проверки

1. Выполнить `npm run build`, затем `npm start`; убедиться, что сервер сообщает адрес `0.0.0.0` и фактически используемый порт.
2. Открыть `/` и `/index.html`; проверить, что оба адреса отдают существующий `index.html`.
3. Запросить `GET /api/menu`; проверить наличие трёх позиций: «Коричная капибара», «Ванильный круассан», «Шоколадный круассан».
4. Отправить `POST /api/selection` с валидным `id`, затем с неизвестным `id` и некорректным JSON; проверить локальное подтверждение и отказ для неверных данных.
5. Отправить `POST /api/reset`; проверить сообщение о сбросе и убедиться, что сервер не хранит выбор.
6. Запросить `GET /api/status`; проверить `ok: true` и актуальное серверное время. Запросить неизвестный маршрут и проверить явный HTTP 404.
7. Для проверки деплоя подключить репозиторий в панели Amvera, дождаться успешной сборки и запуска из `amvera.yaml`, затем открыть опубликованный адрес и проверить страницу и API.
