# Спецификация

## Назначение

Одна общая страница показывает расписание прогулок Бориса на текущую дату. Слоты фиксированы: 09:00, 11:00, 13:00, 15:00 и 17:00. Пользователь занимает свободный слот, указав ФИО; запись видна всем клиентам этого сервера.

## API

- `GET /api/state` возвращает `{date, slots, lastFeeding}`. У каждого слота есть `id`, `time` и `fullName` (строка или `null`).
- `POST /api/bookings` принимает JSON вида `{"slotId":"09:00","fullName":"Имя Фамилия"}`. Успешная запись отвечает HTTP 201; занятый слот — HTTP 409; неверный JSON, слот или ФИО — HTTP 400.
- `GET /api/status` возвращает JSON с `ok: true` и временем сервера в ISO 8601.
- Любые остальные сочетания пути и HTTP-метода получают HTTP 404.

## Технические ограничения

- Сервер использует Node.js 18+, встроенные `node:http`, `node:fs`, `node:path` и пакет SQLite `better-sqlite3`.
- SQLite — единственный источник состояния. По умолчанию база создаётся в `data/boris.sqlite`; путь задаётся переменной `DATABASE_PATH`.
- Уникальность пары «дата + слот» обеспечивается первичным ключом SQLite, чтобы конкурентные запросы не могли занять один слот дважды.
- Дата определяется в `Europe/Moscow` или часовом поясе из `APP_TIME_ZONE`.
- Интерфейс обновляет расписание каждые четыре секунды и при возвращении вкладки в фокус.
- Запуск слушает `0.0.0.0`; порт берётся из `PORT`, локальное значение по умолчанию — `3000`.
- Сборка проверяет синтаксис `server.js`; Amvera использует Node.js 18, `npm run build`, `npm run start` и контейнерный порт `3000` из `amvera.yaml`.
