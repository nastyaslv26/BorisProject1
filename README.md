# Кто выгуливает Бориса

Самостоятельное Node.js-приложение с одной общей страницей для записи сотрудников на прогулку с собакой Борисом. Это отдельный кейс, а не переделанная версия прошлого учебного проекта.

## Локальный запуск

Приложение предназначено для локального запуска через Node.js. После появления рабочего кода используйте команду запуска и локальный адрес, указанные в проекте; затем откройте страницу в браузере. Страница использует локальный сервер для чтения и записи общего состояния в SQLite. Точная команда запуска будет зафиксирована вместе с реализацией.

## Сценарий

Без регистрации сотрудник видит текущую дату, пять фиксированных слотов на эту дату и карточку последнего кормления. Он вводит ФИО и записывается в свободный слот. Сервер не допускает повторную запись в занятый слот. Состояние хранится в SQLite, переживает обновление страницы и доступно при открытии приложения во втором браузере.

Для разработки и демонстрации использовать только синтетические ФИО и данные. Подробные требования — в [spec.md](./spec.md), правила работы — в [AGENTS.md](./AGENTS.md), этапы — в [PLAN.md](./PLAN.md).
