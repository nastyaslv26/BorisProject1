# Кто выгуливает Бориса

Node.js-сервер отдаёт существующий интерфейс из `index.html` и предоставляет небольшой API с фиксированным меню. Выбор подтверждается только для текущего запроса: сервер не хранит его и не использует базу данных.

## Локальный запуск

Требуется Node.js 18 или новее. Из корня проекта выполните:

```sh
npm run build
npm start
```

Откройте [http://localhost:3000](http://localhost:3000). Сервер использует `PORT`, если переменная задана, и порт `3000` при локальном запуске.

## API

- `GET /api/menu` возвращает три фиксированные позиции.
- `POST /api/selection` проверяет идентификатор позиции и возвращает локальное подтверждение.
- `POST /api/reset` возвращает сообщение о сбросе выбора; состояние не сохраняется.
- `GET /api/status` возвращает признак готовности и текущее серверное время.

Форматы запросов и ограничения описаны в [spec.md](./spec.md). Текущий API не записывает выбор и не реализует сохранение расписания прогулок из интерфейса.

## Деплой на Amvera

В корне проекта находится `amvera.yaml`: сборка запускает `npm run build`, приложение запускается командой `npm run start` на контейнерном порту `3000`. Для публикации подключите GitHub-репозиторий в панели Amvera и создайте Node.js-приложение с конфигурацией из этого файла. После успешного деплоя откройте выданный Amvera адрес; отдельные базы данных, тома и переменные приложения не нужны.

Подробные ограничения приведены в [spec.md](./spec.md), порядок ручной проверки — в [PLAN.md](./PLAN.md). Правила проекта — в [AGENTS.md](./AGENTS.md).
