# Кто выгуливает Бориса

Общее расписание прогулок Бориса на сегодня: пять слотов в 09:00, 11:00, 13:00, 15:00 и 17:00. Записи по ФИО хранятся в SQLite на сервере, поэтому занятые слоты видны другим браузерам. Свободное время автоматически обновляется каждые четыре секунды.

## Локальный запуск

Требуется Node.js 18 или новее. Из корня проекта выполните:

```sh
npm install
npm run build
npm start
```

Откройте [http://localhost:3000](http://localhost:3000). Сервер использует `PORT`, если переменная задана, и порт `3000` при локальном запуске.

Локально файл базы данных по умолчанию находится в `data/boris.sqlite`; на Amvera он хранится в постоянном `/data/boris.sqlite`. Путь можно изменить через `DATABASE_PATH`; часовой пояс расписания по умолчанию — `Europe/Moscow`, его можно изменить через `APP_TIME_ZONE`.

## API

- `GET /api/state` возвращает сегодняшнюю дату и состояние пяти слотов.
- `POST /api/bookings` принимает `slotId` и `fullName`; при занятом слоте сервер отвечает HTTP 409.
- `GET /api/status` возвращает признак готовности и текущее серверное время.

Форматы запросов и ограничения описаны в [spec.md](./spec.md). Карточка последнего кормления пока показывает отсутствие данных.

## Деплой на Amvera

В корне проекта находится `amvera.yaml`: сборка запускает `npm run build`, приложение запускается командой `npm run start` на контейнерном порту `3000`, а постоянное хранилище монтируется в `/data` для базы SQLite. Для публикации подключите GitHub-репозиторий в панели Amvera и создайте Node.js-приложение с конфигурацией из этого файла.

Порядок ручной проверки — в [PLAN.md](./PLAN.md). Правила проекта — в [AGENTS.md](./AGENTS.md).
