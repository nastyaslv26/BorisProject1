# Кто выгуливает Бориса

Страница записи на прогулки с Борисом. Пять временных окон заданы в приложении и не загружаются из внешнего расписания. Общая запись хранится на сервере и видна посетителям из разных браузеров.

## Запуск и проверка

Требуется Node.js 18 или новее. В корне проекта выполните:

```sh
npm install
npm run build
npm start
```

Откройте [http://localhost:3000](http://localhost:3000). Сервер слушает `0.0.0.0`; если задан `PORT`, используется он, иначе — порт `3000`.

Если открыть `index.html` напрямую, страница перенаправит на [общий сайт](https://progulka-s-borisom-nastyaslv.mia0.amvera.tech/), чтобы все браузеры использовали одну серверную базу. Для работы общего расписания опубликованный сайт должен быть доступен.

## Запись

- Доступны только окна `09:00`, `11:00`, `13:00`, `15:00` и `17:00` текущей даты.
- `GET /api/state` возвращает фиксированные окна, сохранённые записи на текущую дату и последнюю отметку кормления (ФИО и московские дату/время) из SQLite.
- `POST /api/bookings` с `Content-Type: application/json` и телом `{"slotId":"09:00","fullName":"ФИО"}` сохраняет запись. Другой тип содержимого получает HTTP 415; тело ограничено 8 КиБ, превышение лимита — HTTP 413. Повторная запись в занятое окно получает HTTP 409; некорректный слот или ФИО — HTTP 400.
- `POST /api/feedings` с `Content-Type: application/json` и телом `{"fullName":"ФИО"}` сохраняет отметку кормления в SQLite и возвращает HTTP 201. Пустое после удаления пробелов, недопустимое или слишком длинное ФИО получает HTTP 400.
- Локально база `boris.sqlite` создаётся автоматически в каталоге проекта. На Amvera она хранится в постоянном `/data/boris.sqlite`; путь можно переопределить переменной `DATABASE_PATH`.
- Дата записи, `created_at` в SQLite и время в `GET /api/status` используют часовой пояс `Europe/Moscow` и формат ISO 8601 с часовым смещением.
- `GET /api/status` возвращает `ok: true` и текущее серверное время.
- Все остальные маршруты возвращают явный HTTP 404.


## Деплой на Amvera

Подключите GitHub-репозиторий проекта в панели Amvera и выберите Node.js-приложение. Корневой [amvera.yaml](./amvera.yaml) задаёт сборку через `npm run build`, запуск через `npm run start`, порт контейнера `3000` и постоянное хранилище `/data`. На Amvera приложение автоматически размещает базу в `/data/boris.sqlite`, чтобы записи сохранялись между перезапусками.

## Что не входит в проект

в текущем проекте не предполагается авторизации пользователей, ролей, управления ролями, нельзя отменить запись, нет уведомлений для пользователей, также не хранится история записей, нет интеграций с другими системами.

## Следующие шаги
Для удобства работы с проектом - добавить отмену записи, если пользователь передумал, это следующий логичный шаг. Затем я бы добавила уведомления чтобы не забывать о прогулке. После этого можно сделать авторизации и роли для разных уровней пользователей.
